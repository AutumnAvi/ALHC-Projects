Latest phase: Portfolios and reporting — named collections of projects with their own `portfolio_members` roles (owner / admin / editor / viewer), a deduped progress overview, a cross-project report (by project / by assignee), and a project status (on track / at risk / off track / complete) set by Editors+ (see “Portfolios and reporting model” in AGENTS.md). Portfolio membership never grants project access: everything shown through a portfolio is filtered by `has_project_role(project, 'viewer')`. Project data stays gated by `project_members` roles (Teams & permissions); the email allowlist remains the outer sign-in gate.
